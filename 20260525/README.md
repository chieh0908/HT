# 《幻塔》Discord簽到活動(6.0版本)

《幻塔》(Tower of Fantasy, HT) 6.0 版本 Discord 帳號綁定簽到活動網頁。授權者綁定《幻塔》遊戲帳號與 Discord 帳號後，至官方 Discord 群組每日手動點擊簽到即可領取每日獎勵，首次完成綁定並簽到可額外獲得墨晶獎勵。

- 活動時間：2026/5/25 － 2026/6/14 23:59（UTC+8）

## 遊戲背景

輕科幻開放世界手遊《幻塔》，身為「拓荒者」的你，失去記憶在「艾達星」醒來。原能因意外輻射瀰漫星球，文明瀕臨毀滅，理念不同的「艾達之子」與「海嘉德」不斷對立，艾達星最終的命運如何，等待玩家自行揭曉。

## 活動玩法

- **KV 主視覺（`kv_zone`）**：效果影片背景、Logo、社群連結（官網／Facebook／YouTube／Discord）按鈕，以及往下導引按鈕捲動至綁定區塊。
- **帳號綁定區（`events_2` / `#login_area`）**：左側為《幻塔》帳號登入狀態（`ht_acct`）、右側為 Discord 帳號登入狀態（`dc_acct`），中間以 `connect` 圖示串接；兩者未登入時各自顯示「登入」按鈕，完成登入後切換為顯示已綁定資訊（伺服器名稱／角色名稱，或 Discord 使用者名稱），並以 3 張步驟圖（`step_01`～`step_03`）說明綁定流程。
- **綁定／解除綁定彈窗**：確認綁定（`#modal_01`）→綁定成功（`#modal_02`）；確認解除綁定（`#modal_03`）→解除成功（`#modal_04`）／解除失敗因未滿 30 天（`#modal_05`）；若《幻塔》帳號下有多個角色，另提供「選擇角色」彈窗（`#modal_06`）供切換要綁定的角色。
- **規則說明區（`events_3`）**：顯示活動時間、參與條件與注意事項條款，內容以 `{NOTICE_LIST}` 樣板字串呈現，由 `js/20260525.js` 的 `ViewObj` 填入。

## 版面規格 / RWD

- 採用 Bootstrap 斷點（767px／900px／1200px／1470px）做響應式排版，主視覺與步驟圖等多數素材皆提供桌機（`_pc`）與手機（`_mo`／`_m`）兩套圖源依裝置寬度切換，而非單一素材等比縮放。
