# 《幻塔》6.2版本「虛無與夢境的坐標」永恆島貴賓邀請活動網頁 (htactivity_260804)

《幻塔》(Tower of Fantasy, HT) 6.2 版本「人拉人」回流／拉新活動網頁。授權者可生成專屬邀請碼邀請新玩家註冊或邀請老玩家回流，雙方透過完成召集任務取得抽獎卷，再消耗抽獎卷參與跑馬燈抽獎，最高可獲得墨晶 *6000 等獎勵。

- 活動時間：2026年8月4日 12:00(UTC+8) ～ 2026年9月14日 23:59(UTC+8)

## 活動玩法

網頁依身份分成三份獨立進站頁面，彼此共用同一套樣式與腳本：

- **old.html（活躍召集／邀請人視角）**：頂部顯示自己的邀請碼與「已邀請 n/4 人」進度、4 個受邀玩家欄位；點擊分享／邀請圖示可複製專屬邀請碼，跳出「邀請碼已成功複製」提示彈窗（`#eventAlert`）。任務列表為邀請端任務：首次分享、邀請 1 位／4 位玩家、受邀玩家完成全部任務 1 名／2 名，對應解鎖抽獎卷獎勵。
- **new.html（新人召集／受邀新玩家視角）**：進站時自動彈出輸入邀請碼彈窗（`#enter_code_modal`，10 格數字輸入），綁定邀請人後顯示「受邀人ID／邀請人ID」。任務列表為新玩家任務：加入小隊、登入遊戲 1 天／3 天、消耗赤核 *10、解鎖武器「仙女環」。
- **back.html（回流召集／受邀回歸玩家視角）**：版面與 new.html 相同（同樣進站彈出輸入邀請碼彈窗），僅文案改為「回流召集」。參與條件為角色等級 ≥30 且活動開始前 30 天內未登入的回歸玩家。
- **永恆島貴賓邀請活動（跑馬燈抽獎，三頁共用的第二個 tab）**：9 格獎品以跑馬燈形式繞圈點亮，消耗召集任務取得的抽獎卷進行抽取，單次最高可得墨晶 *6000，其餘獎品包含赤核／特種憑證－格爾菲茵、金核、檢索憑證、超荷裝備自選箱等；抽獎卷用盡時改顯示「次數已用光，請完成任務解鎖更多抽獎機會」提示。
- **其他彈窗**：召集任務規則（依身份顯示活躍／新人／回流召集規則）、跑馬燈抽獎規則與獎勵列表、恭喜獲得獎勵／次數用光提示。

## 核心技術實作

- **三份進站頁面對應三種身份**：old.html／new.html／back.html 共用 `css/main.css`、`js/main.js`、`js/20260804.js`、`js/demo.js`，僅頂部邀請資訊區塊與任務列表內容依身份不同；old.html 為邀請人視角不需綁定邀請碼，new.html／back.html 則在 `window.onload` 時以 `.modal('show')` 自動彈出輸入邀請碼彈窗。
- **邀請碼輸入框**（`js/main.js`）：10 格數字輸入框以 `keyup`／`input` 事件限制只能輸入數字，輸入後自動跳下一格、按 Backspace 跳回上一格；另監聽 `paste` 事件，將剪貼簿內容依序拆入各格並同步寫入隱藏欄位 `#verificationCode`，供後續串接後端驗證邀請碼使用。
- **跑馬燈抽獎動畫**（`js/demo.js`，`runMarqueeAnimation`）：9 個獎品格依視覺排列（上排 5 格、下排 4 格）組成順時針繞圈順序 `[0,1,2,3,4,8,7,6,5]`，抽獎時固定跑 2 圈後停在中獎格；`getDelay()` 依目前進度做「先快後慢」的 easeOut 緩動（前 60% 每格固定 60ms，後 40% 以二次曲線漸增至最多約 310ms），模擬跑馬燈逐漸變慢停下的手感。目前以 `Math.random()` 於前端亂數決定中獎格（demo 階段），正式串接時應改由後端回傳中獎結果與剩餘抽獎卷數。
- **文案集中管理**（`js/20260804.js`，`ViewObj`）：將活躍／新人／回流召集三種身份的規則彈窗標題與內文、跑馬燈規則與獎勵說明、輸入邀請碼彈窗提示文字集中成一份物件，對應 HTML 中 `{xxx}` 樣板字串，方便行銷文案調整時不需改動 HTML 結構；頁面同時保留 `https://ids.iwplay.com.tw/eventjson/eventjson.js` 供正式環境串接後台可編輯文案的掛載點。
- **Tab 切換**：點擊召集任務／永恆島貴賓邀請活動兩個分頁時，同步切換對應的「詳細規則」連結顯示（`game_rule`／`mono_rule`）與主視覺背景圖（`bg01`／`bg02`）、標題透明度，維持單一頁面內兩套玩法共用同一張 KV 主視覺。

## 版面規格 / RWD

- 全站以 `vw` 為單位做流動式等比縮放版面，未採用固定寬度 + rem 縮放的作法。
- 僅支援橫式瀏覽：以 CSS `@media screen and (orientation: portrait)` 偵測直式時，隱藏主要內容（`.kv`）並顯示全螢幕遮罩提示（`.note_flex`，「請使用橫式閱覽！- 鏡都安全部關心您 -」），橫式時再恢復顯示主要內容。
