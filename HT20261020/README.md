# 《幻塔》官方網站

《幻塔》(Tower of Fantasy, HT) 官方網站首頁與角色情報頁。本次更新（261020 版本，對應遊戲 6.4 版本）於首頁角色輪播與角色情報頁新增角色「芮娜」卡片，同步更新首頁主視覺、遊戲特色輪播與粉絲團全角色合照背景，並調整首頁角色輪播的新舊排序。

- 正式網址：https://www.hotta.com.tw/

## 遊戲背景

輕科幻開放世界手遊《幻塔》，身為「拓荒者」的你，失去記憶在「艾達星」醒來。原能因意外輻射瀰漫星球，文明瀕臨毀滅，理念不同的「艾達之子」與「海嘉德」不斷對立，艾達星最終的命運如何，等待玩家自行揭曉。

## 頁面內容

- **首頁（`index.html`）**：Nav 選單＋音樂／社群連結、Header 主視覺影片與下載按鈕（iOS／Android／Windows／APK／PS5）、News 新聞資訊輪播（最新／新聞／活動／系統四個分類）、Portrait 角色輪播（首頁僅呈現最新 4 位角色，點擊可進入角色情報頁）、Features 遊戲特色／商城圖輪播、Fans 粉絲團專區（全角色合照背景＋FB 嵌入）；GameInfo／Footer 區塊由遠端 `main_link.js` 動態注入內容。
- **角色情報頁（`portrait.html`）**：以 Swiper 橫向輪播呈現站上所有角色，「最新角色」區塊固定置於最前，其餘「舊角色」依版本新舊依序往後排列，可切換瀏覽每位角色的立繪、姓名、聲優與一句台詞／語音。

- **新增角色「芮娜」（CV 森山由梨佳）**：首頁角色輪播以最新角色置頂顯示（r73），原排序第 1～3 位的佐伊（r72）、格爾菲茵（r71）、碎骨（r70）依序退後一位，原第 4 位「赫莫菲斯」（r69）退出首頁輪播（仍保留於角色情報頁完整列表）。角色情報頁「最新角色」區塊同步將格爾菲茵移至「舊角色」區（與碎骨並列），佐伊則維持留在最新角色區；下方縮圖列表（`.role_list`）也同步把 r73 加到最前面，並補上對應的桌機／手機版縮圖樣式。
